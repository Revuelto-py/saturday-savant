Savant Forecast

A win probability for every game, set before kickoff and never touched again, then graded against what happened.

This page is the whole record: how the number is built, how often it has been right, and the games where it was most confident and most wrong.

Six steps, from the question to the grade. Select one to jump to it.

1

One question, asked before kickoff

2017–23 training seasons; tuned on 2024, tested on 2025

The forecast answers a single thing: what are the odds each team wins this game? It is a logistic regression, the plainest model that does this job, trained on 2017 through 2023, tuned on 2024, and tested on a 2025 season it had never seen.

A second output turns the same inputs into an expected margin, which is where the "by about 10" line on a game page comes from.

2

It is only allowed to know what you knew

16 inputs, every one available before kickoff

Every input has to have been available before the game kicked off. That sounds obvious and is easy to get wrong: a team's final Savant Rating or end-of-season SP+ is an average that already contains the result of this game, so a model fed those numbers looks brilliant and predicts nothing.

The features are rebuilt week by week by replaying the season forward, and the same code produces them for training and for live forecasting, so the two can't drift apart.

3

What actually moves the number

{{ '%.0f'|format(top_fam[1]) }}% of the model's weight is {{ top_fam[0]|lower }}

Sixteen inputs, in four families. The bars are each family's share of the model's total weight once every input is put on the same scale.

The single biggest lever is Elo, which is how the model knows a 4-1 team beat nobody. In week 1 there is no in-season evidence, so recruiting and returning production carry the forecast almost alone; from week 2 on, what teams have actually done takes over and the preseason signal fades.

4

Two models, because one can't see FCS

{{ fcs.n }} FCS games sent to a four-input model

The main model compares two FBS teams by difference, their Elo gap and their recruiting gap, and an FCS opponent has none of those numbers. Rather than invent them, those games go to a separate four-input model that reads only the FBS side's strength.

Its hit rate sounds impressive and mostly isn't, since FBS teams win these games about nine times in ten. It is judged on whether it can tell a genuine 99% from a weak FBS team on the road, and it can.

5

Nothing gets rewritten after the fact

{{ '{:,}'.format(fbs.n + fcs.n) }} forecasts frozen and graded

Once a game kicks off its forecast is frozen. Later weeks re-forecast everything still unplayed, since a team that fires its coach in October changes every remaining game on its schedule, but a graded prediction is never revised.

The 2025 forecasts are the test season: the finished model run as of each week, using only what was known then. From 2026 every forecast was published on the site before its game kicked off.

Does 70% mean 70%?

Being right often is not the same as being honest. A model that says 90% should be wrong one game in ten; if it is never wrong, it was too timid. Each point groups the games the model gave roughly the same confidence and compares what it claimed with what happened.

Where it earns its keep

Split every graded game by how it finished. The pattern is the most useful thing on this page, and the least flattering.

On blowouts it is right almost every time; on one-possession games it is barely better than a coin flip. That is less a flaw than a description of college football: a fourth-quarter two-point try is not predictable from recruiting and Elo. It is why the forecast is published as a probability instead of a pick.
