How It Works

1 · One question, asked before kickoff

The forecast answers a single thing: what are the odds each team wins this game? It is a logistic regression — the plainest model that does this job — trained on {{ '2017' }} through {{ '2023' }}, tuned on 2024, and tested on a 2025 season it had never seen. A second output converts the same inputs into an expected margin, which is where the "by about 10" line on a game page comes from.

2 · It is only allowed to know what you knew

This is the constraint the whole thing is built around. Every input has to have been available before the game kicked off. That sounds obvious and is easy to get wrong: a team's final Savant Rating or end-of-season SP+ is an average that already contains the result of this game, so a model fed those numbers looks brilliant and predicts nothing. Same-season ratings and AP polls are excluded for exactly that reason. The features are rebuilt week by week by replaying the season forward, and the same code path produces them for training and for live forecasting, so the two can't drift apart.

3 · What actually moves the number

Sixteen inputs, in four families. The bars are each family's share of the model's total weight once every input is put on the same scale:

The single biggest lever is Elo — a running strength number updated game by game all the way back to 2016, which is how the model knows a 4-1 team beat nobody. In week 1 there is no in-season evidence at all, so recruiting and returning production carry the forecast almost by themselves; from week 2 on, what teams have actually done takes over and the preseason signal fades.

4 · Two models, because one can't see FCS

The main model compares two FBS teams by difference — their Elo gap, their recruiting gap — and an FCS opponent has none of those numbers. Rather than invent them, non-FBS games go to a separate four-input model that reads only the FBS side's strength. It is right about 96% of the time, which sounds impressive and mostly isn't; it is judged on whether it can tell a genuine 99% from a weak FBS team on the road, and it can.

5 · Nothing gets rewritten after the fact

Once a game kicks off its forecast is frozen. Later weeks re-forecast everything still unplayed — a team that fires its coach in October changes every remaining game on its schedule — but a graded prediction is never revised. The accuracy on this page is what the site actually said at the time, not a number reconstructed afterwards with the benefit of knowing how the season went.

The dashed line is 50% — a coin flip.

On games decided by four scores or more it is right almost nine times in ten, and on one-possession games it is barely better than a coin flip. That is not a flaw to be fixed so much as a description of college football: a two-point conversion in the fourth quarter is not predictable from recruiting rankings and Elo. It is the reason the forecast is published as a probability instead of a pick.
